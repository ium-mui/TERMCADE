# Security

[English](SECURITY.md) · [한국어](docs/ko/SECURITY.md) · [简体中文](docs/zh-CN/SECURITY.md)

TERMCADE is a local terminal game. Ordinary crashes, display problems, game-rule mistakes, and wallet-balancing issues should use the normal bug report.

Use GitHub's [private vulnerability report](https://github.com/ium-mui/TERMCADE/security/advisories/new) only when a problem could execute unintended code, access or damage files outside TERMCADE's own data, expose sensitive information, or compromise release artifacts or dependencies.

Include the affected version, operating system, realistic impact, and minimal reproduction steps. Security fixes target the latest release and are published through the normal tested release process.
