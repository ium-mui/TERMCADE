## Getting help

1. Read the [README](README.md), [game reference](docs/GAMES.md), and [development guide](docs/DEVELOPMENT.md).
2. Search open and closed GitHub issues.
3. If no answer exists, open the appropriate issue form:
   - Use **Support request** for a usage or development question.
   - Use **Bug report** when documented behavior is reproducibly wrong.
   - Use **Feature request** for new behavior.
   - Use **Documentation issue** for unclear or missing guidance.

Include the TERMCADE version or commit, operating system, terminal, Rust version when building from source, exact command, expected result, actual result, and sanitized logs. A small reproducible example receives the fastest help.

## Response expectations

TERMCADE is maintained by volunteers. Responses, fixes, and feature delivery have no guaranteed schedule. Please do not privately contact individual contributors for routine support or repeatedly bump an issue without new information.

Maintainers may close support requests that are inactive, cannot be reproduced, are outside project scope, or omit requested information. A closed issue can be reconsidered when meaningful new evidence is provided.

## Security and privacy

Never post credentials, tokens, private history data, or personal information. Redact paths and terminal output when needed. Report suspected vulnerabilities privately through [SECURITY.md](SECURITY.md), not through a support issue.
