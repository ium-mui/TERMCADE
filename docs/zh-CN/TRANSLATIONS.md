# 语言支持

[English](../TRANSLATIONS.md) · [한국어](../ko/TRANSLATIONS.md) · [简体中文](TRANSLATIONS.md)

TERMCADE 的目标是让项目文档可以用多种语言阅读。目前支持英语、韩语（`ko`）和简体中文（`zh-CN`），并可按相同结构继续增加其他语言。

## 当前文件结构

```text
README.md                  英语版本
README.ko.md               韩语版本
README.zh-CN.md            简体中文版本
docs/<NAME>.md             英语版本
docs/ko/<NAME>.md          韩语版本
docs/zh-CN/<NAME>.md       简体中文版本
```

英语文件位于根目录只是遵循常见的 GitHub 仓库布局，并不表示英语在规则上具有更高优先级。所有受支持的语言版本都应描述相同的命令和行为。内容不一致时，应检查代码、测试和当前版本，而不是默认某种语言正确。

## 更新文档

- 可以从任一受支持的语言开始更正或改进。
- 尽量在同一个 PR 中同步相关语言版本。
- 命令、Rust 标识符、路径、按键名称和版本号保持不变。
- 应按目标语言自然表达，不必照搬句子结构。
- 如果无法准确审阅其他语言，请在 PR 中标记需要语言审阅。无需为每个小差异单独创建 Issue。
- 运行 `./scripts/check.sh`；CI 会检查每种受支持语言的文档集合。

## 添加新语言

使用 `ja`、`pt-BR` 等 BCP 47 语言标签。

1. 添加 `README.<locale>.md` 和包含相同项目文档的 `docs/<locale>/`。
2. 在每种语言文档的导航行中加入新语言。
3. 扩展 `scripts/check-docs.sh`，检查新的文档集合。
4. 创建 PR，说明哪些页面已审阅、哪些仍需要帮助。

机器翻译可以用于生成初稿，但合并前必须检查命令和技术含义。
