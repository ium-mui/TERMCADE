# 安全

[English](../../SECURITY.md) · [한국어](../ko/SECURITY.md) · [简体中文](SECURITY.md)

TERMCADE 是本地终端游戏。普通崩溃、显示问题、游戏规则错误和钱包平衡问题请使用普通 Bug Issue。

只有当问题可能导致意外代码执行、访问或破坏 TERMCADE 数据之外的文件、泄露敏感信息，或危及发布文件和依赖项时，才使用 GitHub 的[私密漏洞报告](https://github.com/ium-mui/TERMCADE/security/advisories/new)。

请提供受影响版本、操作系统、实际影响和最小复现步骤。安全修复以最新版本为目标，并通过正常的测试和发布流程交付。
