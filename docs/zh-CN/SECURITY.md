# 安全政策

[English](../../SECURITY.md) · [한국어](../ko/SECURITY.md) · [简体中文](SECURITY.md)

## 支持版本

TERMCADE 为最新发布的 minor 版本线提供安全修复。开发快照和旧版本可用于复现，但修复只从当前 `main` 发布。

| 版本 | 支持状态 |
| --- | --- |
| 最新 Release | 是 |
| 更早 Release | 否 |
| 未发布的 `main` | 尽力支持 |

## 报告漏洞

不要创建公开 Issue。使用 GitHub [私密漏洞报告](https://github.com/ium-mui/TERMCADE/security/advisories/new)，并包含：

- 受影响版本、commit、操作系统和终端
- 漏洞类别和现实影响
- 最小复现步骤或 proof of concept
- 前置条件，以及是否需要不可信输入
- 已知的缓解方法
- 是否已在其他地方披露

删除无关个人数据，并且只测试你拥有或获准评估的系统和用户。

## 响应流程

维护者目标是在 7 天内确认完整报告，并在 14 天内提供初步评估，但不作保证。团队会私下验证影响、协调修复和 advisory，并尽可能与报告者约定披露日期。

接受的修复即使在私有 fork 或限制分支中，也必须遵循正常评审和 CI。安全版本使用新的 SemVer patch 或更高版本，绝不重写旧标签和 Release。除非报告者希望匿名，否则会提供署名。

TERMCADE 是本地终端游戏。历史文件解析与替换、终端恢复、输入、Release 完整性、自动化和依赖是重要安全边界。仅修改本地游戏钱包且没有更广泛完整性或代码执行影响的问题通常按 Bug 处理。
