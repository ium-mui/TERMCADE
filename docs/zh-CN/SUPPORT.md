# 支持

[English](../../SUPPORT.md) · [한국어](../ko/SUPPORT.md) · [简体中文](SUPPORT.md)

## 获取帮助

1. 阅读 [README](../../README.zh-CN.md)、[游戏文档](GAMES.md)和[开发指南](DEVELOPMENT.md)。
2. 搜索开放和已关闭的 GitHub Issue。
3. 没有答案时选择正确的 Issue 表单：
   - 使用或开发问题使用 **Support request**
   - 文档规定的行为可复现地出错使用 **Bug report**
   - 新行为使用 **Feature request**
   - 缺失或不清楚的说明使用 **Documentation issue**

请提供 TERMCADE 版本或 commit、操作系统、终端、从源码构建时的 Rust 版本、准确命令、预期和实际结果，以及删除敏感信息后的日志。最小复现示例最容易获得帮助。

## 响应预期

TERMCADE 由志愿者维护，不保证响应、修复或功能交付时间。请勿为日常支持私下联系个人贡献者，也不要在没有新信息时反复顶起 Issue。

长期无活动、无法复现、超出范围或缺少所需信息的请求可能被关闭。提供有意义的新证据后可以重新考虑。

## 安全与隐私

不要发布 credential、token、私人历史数据或个人信息。必要时隐藏路径和终端输出。疑似漏洞请按[安全政策](SECURITY.md)私密报告，不要创建支持 Issue。
