# 行为准则

[English](../../CODE_OF_CONDUCT.md) · [한국어](../ko/CODE_OF_CONDUCT.md) · [简体中文](CODE_OF_CONDUCT.md)

## 我们的承诺

TERMCADE 的贡献者、维护者和社区成员承诺提供友好、安全且无骚扰的环境，不因年龄、体型、残障、族裔、性别认同或表达、经验水平、国籍、外貌、种族、宗教、性认同或取向、社会经济地位或技术选择而区别对待。

## 期望行为

- 保持尊重、耐心和建设性。
- 批评观点和变更，不攻击提出者。
- 平和接受反馈并承认错误。
- 尊重隐私、边界和不同沟通方式。
- 使用国际社区易于理解的包容性语言。
- 把社区安全和项目健康放在赢得争论之前。

## 不可接受的行为

- 骚扰、威胁、跟踪、歧视或持续干扰
- 性化语言、图像或不受欢迎的关注
- 侮辱、人身攻击、trolling 或故意煽动
- 未经明确允许公开私人信息
- 冒充、spam、操纵或故意误导
- 报复善意举报者
- 在专业社区中可合理视为不当的其他行为

这些规则适用于仓库活动、项目交流、活动，以及代表 TERMCADE 的公开空间。

## 举报与执行

通过[私密 security advisory](https://github.com/ium-mui/TERMCADE/security/advisories/new)向维护者报告行为问题，并在标题中写 `Code of Conduct`。不要提供超出必要范围的个人信息。

维护者会在可行时确认举报、保护举报者隐私、听取相关各方、私下记录决定，并仅披露社区安全所需的信息。有利益冲突的维护者必须回避。

处理措施包括私下纠正、正式警告、限定期限的参与限制，以及对严重或重复违规的永久封禁。无法证实的举报不会自动被视为恶意，但故意虚假举报也可能违反本政策。
