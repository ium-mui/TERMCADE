# 보안

[English](../../SECURITY.md) · [한국어](SECURITY.md) · [简体中文](../zh-CN/SECURITY.md)

TERMCADE는 로컬 터미널 게임입니다. 일반적인 충돌, 화면 문제, 게임 규칙 오류, 지갑 밸런스 문제는 보통의 버그 이슈로 알려 주세요.

의도하지 않은 코드 실행, TERMCADE 데이터 외부 파일 접근·손상, 민감한 정보 노출, 릴리스 파일이나 의존성 훼손 가능성이 있는 문제만 GitHub의 [비공개 취약점 신고](https://github.com/ium-mui/TERMCADE/security/advisories/new)를 사용합니다.

영향받는 버전, 운영체제, 현실적인 영향, 최소 재현 절차를 포함해 주세요. 보안 수정은 최신 릴리스를 대상으로 하며 일반적인 테스트와 릴리스 절차를 통해 배포합니다.
