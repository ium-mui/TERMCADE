# TERMCADE 문서

[English](../README.md) · [한국어](README.md) · [简体中文](../zh-CN/README.md)

TERMCADE 문서는 영어·한국어·중국어 간체를 동등한 버전으로 관리합니다. 저장소의 파일 배치는 위치를 정하기 위한 규칙일 뿐 특정 언어에 우선권을 주지 않습니다. 문서 내용이 다르면 코드, 테스트, 현재 릴리스의 동작을 확인한 뒤 관련 문서를 바로잡습니다.
