# 게임과 단계

## 아케이드 게임

| 게임 | 단계 | 난이도 차이 | 주요 조작 |
| --- | --- | --- | --- |
| 지뢰찾기 | `beginner` | 9×9, 지뢰 10개 | 이동, `Enter` 공개, `F` 깃발 |
| 지뢰찾기 | `intermediate` | 16×12, 지뢰 30개 | 이동, `Enter` 공개, `F` 깃발 |
| 지뢰찾기 | `expert` | 24×16, 지뢰 70개 | 이동, `Enter` 공개, `F` 깃발 |
| 커넥트 포 | `easy` | AI가 유효한 열을 무작위 선택 | 좌우, `Enter` 놓기 |
| 커넥트 포 | `normal` | AI가 즉시 승리와 방어를 판단 | 좌우, `Enter` 놓기 |
| 커넥트 포 | `hard` | AI가 알파-베타 가지치기로 5수 탐색 | 좌우, `Enter` 놓기 |
| 카드 짝맞추기 | `small` | 4×3, 6쌍 | 이동, `Enter` 공개·확인 |
| 카드 짝맞추기 | `classic` | 4×4, 8쌍 | 이동, `Enter` 공개·확인 |
| 카드 짝맞추기 | `grand` | 6×4, 12쌍 | 이동, `Enter` 공개·확인 |
| 미로 탈출 | `alley` | 15×9 완전 미로 | 방향키 또는 `WASD` |
| 미로 탈출 | `labyrinth` | 25×13 완전 미로 | 방향키 또는 `WASD` |
| 미로 탈출 | `abyss` | 35×17 완전 미로 | 방향키 또는 `WASD` |

지뢰찾기의 첫 공개는 항상 안전합니다. 카드 짝맞추기의 틀린 카드는 사용자가 `Enter`로 확인할 때까지 보입니다. 생성된 모든 미로에는 시작점과 출구 사이 경로가 있고, 같은 seed는 같은 지형을 만듭니다.

## 설계 규칙

- 단계는 이름뿐 아니라 규칙, 보드 크기, 속도, AI 동작이 달라야 합니다.
- 랜덤 게임은 실패 재현을 위한 seeded 생성자를 제공합니다.
- 완료 전 `Esc` 또는 `Q`를 누르면 중단 결과를 한 번 기록합니다.
- 새 단계는 최소 `64×24`와 넓은 `120×40` 크기에서 자동 렌더링 검사합니다.
- 아케이드 게임은 카지노 지갑과 분리합니다.

## 기존 게임 확장 단계

| 게임 | 단계 | 차이 |
| --- | --- | --- |
| 스네이크 | `relaxed` | 이동 간격 230ms |
| 스네이크 | `classic-1` | 이동 간격 160ms |
| 스네이크 | `turbo` | 이동 간격 95ms |
| 스도쿠 | `easy` | 단서 목표 46개 |
| 스도쿠 | `classic-1` | 단서 목표 40개 |
| 스도쿠 | `hard` | 단서 목표 32개 |

스도쿠는 해답이 하나뿐인 퍼즐만 생성합니다. 목표 단서 수까지 안전하게 제거할 수 없으면 유일한 해답을 유지하기 위해 단서를 더 남깁니다.
