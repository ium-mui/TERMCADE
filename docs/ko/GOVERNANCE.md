# 프로젝트 거버넌스

[English](../../GOVERNANCE.md) · [한국어](GOVERNANCE.md) · [简体中文](../zh-CN/GOVERNANCE.md)

TERMCADE는 가벼운 유지관리자 주도 모델을 사용합니다. 투명한 결정, 안전한 릴리스, 낮은 기여 장벽을 목표로 합니다.

## 역할

**기여자**는 이슈, 코드, 문서, 번역, 리뷰, 테스트, 커뮤니티 지원에 참여하는 모든 사람입니다. 변경을 제안하고 공개 설계 논의에 참여할 수 있습니다.

**리뷰어**는 하나 이상의 영역에서 지식을 입증한 신뢰받는 기여자입니다. 이슈를 분류하고 공식 리뷰를 할 수 있지만 유지관리자가 아니라면 병합하거나 게시하지 않습니다.

**유지관리자**는 저장소 쓰기 권한을 갖고 범위 결정, 리뷰, 병합, 보안 대응, 릴리스, 자동화, 행동 강령 집행을 담당합니다. 최소 권한과 강한 계정 보안을 사용하고 이해충돌을 공개하며 기여자와 같은 보호 브랜치 규칙을 따릅니다.

## 역할 변경

지속적이고 건설적인 참여, 건전한 기술 판단, 신뢰할 수 있는 리뷰, 프로젝트 가치에 맞는 행동을 기준으로 유지관리자가 리뷰어나 유지관리자를 추천할 수 있습니다. 개인정보가 관련된 논의는 비공개로 하되 확정된 역할 변경은 공개 기록합니다.

누구나 언제든 역할에서 물러날 수 있습니다. 장기 비활동, 계정 보안 상실, 반복된 정책 위반, 안전한 역할 수행 불가 시 유지관리 권한을 제거할 수 있습니다. 사생활과 안전이 허용하면 운영상 이유와 변경을 기록합니다.

## 의사 결정

일상 변경은 PR 리뷰로 결정합니다. 새 아키텍처 경계, 호환되지 않는 저장 형식, 지원 플랫폼·로케일 제거, 라이선스·거버넌스 변경은 구현 전 공개 이슈나 제안이 필요합니다.

중요한 반대를 해결하는 rough consensus를 추구합니다. 합의가 합리적 기간 안에 이뤄지지 않으면 유지관리자가 이유, 대안, 반대 의견을 기록하고 결정합니다. 중요한 이해충돌이 있는 유지관리자는 빠집니다.

릴리스 PR 병합, 비밀 관리, advisory 게시, 긴급 규칙 우회는 유지관리자만 할 수 있습니다. [릴리스 절차](RELEASING.md)를 따르고 우회는 후속 감사를 진행합니다. 다른 자격 있는 유지관리자가 있다면 한 사람이 고위험 보안·거버넌스 변경을 혼자 승인하고 게시하지 않습니다.

거버넌스 변경은 `governance` 레이블 PR로 공개 리뷰 기간과 유지관리자 승인을 거치며 동기와 마이그레이션 영향을 설명합니다.
