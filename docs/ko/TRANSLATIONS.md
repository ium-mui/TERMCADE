# 언어 지원

[English](../TRANSLATIONS.md) · [한국어](TRANSLATIONS.md) · [简体中文](../zh-CN/TRANSLATIONS.md)

TERMCADE는 여러 언어로 프로젝트 문서를 사용할 수 있도록 하는 것을 목표로 합니다. 현재 영어, 한국어(`ko`), 중국어 간체(`zh-CN`)를 지원하며 같은 구조로 다른 언어를 추가할 수 있습니다.

## 현재 파일 구조

```text
README.md                  영어 버전
README.ko.md               한국어 버전
README.zh-CN.md            중국어 간체 버전
docs/<NAME>.md             영어 버전
docs/ko/<NAME>.md          한국어 버전
docs/zh-CN/<NAME>.md       중국어 간체 버전
```

영어 파일이 루트에 있는 것은 일반적인 GitHub 저장소 배치를 따른 것입니다. 영어에 정책상 우선권을 주는 의미는 아닙니다. 지원하는 모든 언어 문서는 같은 명령과 동작을 설명해야 합니다. 내용이 다르면 특정 언어를 정답으로 가정하지 말고 코드, 테스트, 현재 릴리스를 확인합니다.

## 문서 수정

- 지원 언어 중 어느 언어에서든 교정이나 개선을 시작할 수 있습니다.
- 가능하면 같은 PR에서 관련 언어 문서를 함께 갱신합니다.
- 명령, Rust 식별자, 경로, 키 이름, 버전 문자열은 바꾸지 않습니다.
- 문장 구조를 그대로 복사하기보다 각 언어에 자연스럽게 번역합니다.
- 다른 언어를 정확히 검토하기 어렵다면 PR에 언어 검토가 필요하다고 표시합니다. 작은 차이마다 별도 이슈를 만들 필요는 없습니다.
- `./scripts/check.sh`를 실행합니다. CI는 지원 언어별 문서 구성을 확인합니다.

## 새 언어 추가

`ja`, `pt-BR` 같은 BCP 47 언어 태그를 사용합니다.

1. `README.<locale>.md`와 같은 프로젝트 문서를 담은 `docs/<locale>/`를 추가합니다.
2. 각 언어 문서의 탐색 링크에 새 언어를 추가합니다.
3. `scripts/check-docs.sh`가 새 문서 구성을 검사하도록 확장합니다.
4. 검토가 끝난 페이지와 도움이 필요한 페이지를 설명하는 PR을 엽니다.

기계 번역은 초안에 활용할 수 있지만, 병합 전에 명령과 기술적 의미를 확인해야 합니다.
